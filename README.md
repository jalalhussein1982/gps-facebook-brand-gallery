# GPS Facebook cover and profile gallery

A public gallery for choosing and downloading the latest Prague and Jinonice Facebook covers and GPS profile images.

**Gallery:** https://jalalhussein1982.github.io/gps-facebook-brand-gallery/

- Four separate cover PNGs, each 2000 × 800 px.
- Four separate profile PNGs, each 1024 × 1024 px.
- Full-size previews and individual download buttons.
- A ZIP containing all eight images and a short upload guide.
- Responsive static HTML/CSS/JavaScript; no sign-in, tracking, or backend.

GitHub Pages publishes `docs/` from the `main` branch. For a local preview, serve `docs/` with any static HTTP server.

Image credits are in `docs/credits.txt` and the gallery. Artwork is provided for the GPS programme's Facebook page; this repository does not grant a blanket licence to university branding or third-party photography. Font licences are included in `docs/assets/fonts/`.
