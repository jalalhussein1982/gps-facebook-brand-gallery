Ready to update the page?

  1. Download one cover and one profile image.
  2. Open the programme’s Facebook page with your page-admin account.
  3. Use the cover-photo or profile-picture edit control to upload the corresponding PNG.
  4. Check the preview, reposition if needed, then save. Review the result on a phone and a desktop.

Download the short upload guide

A few useful details

The image files contain only the artwork. Gallery titles, buttons and labels are not part of the downloads.

Facebook may crop a cover differently across screens. These previews show the complete artwork; always check the crop in Facebook before saving.

If your browser opens an image instead of downloading it, use its save-image option.

Photography, symbols and credits

The Prague photograph comes from the existing GPS website artwork. The Jinonice campus photograph is by Mojmir Churavy, shared under CC0 on Wikimedia Commons.

The covers use the complete logo from the programme’s website, including its original wording. The wordmark uses dark lettering on white panels and its original white lettering on black and blue panels.

The university-seal profile option uses the supplied Charles University symbol. Typography uses Source Sans 3 and Source Serif 4.
